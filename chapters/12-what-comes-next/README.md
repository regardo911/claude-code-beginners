# Chapter 12: What Comes Next

Two files. `SKILL.md.example` is the shape of a skill file: when it applies, what to do, and
what to check afterwards. Save it as `styling.md` and Claude loads it when it works on a
component, instead of you remembering to say "use the design system" every time.
`next-sprint-plan.md` is the second-sprint worksheet, blank.

Fill in the worksheet. That's the chapter's whole work: pick something you'll actually use,
write the CLAUDE.md before the first line of code, list five to seven features in priority
order, map them onto the hour blocks, and name three Chapter 6 features you skipped.

Done when the worksheet has a project name in it and a filled-in CLAUDE.md sitting in a new
folder.

The skill file is a taste, not the system; skills that update themselves between sessions are
the next book. Today you can copy that one file, adjust the three quality checks to what your
project actually cares about, and see whether Claude's first pass at a component comes back
closer to right.
